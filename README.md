# AGI 法律研究

面向 AI/AGI 监管的法律研究笔记库。目标：把每次监管变动、判例与规则变化，沉淀成**可复用的研究长文**与**投 AI 公司时能直接用的尽调问题**。

**线上地址**：https://github.com/rexlawson/agi-law-research （public，main 分支）

## 这个仓库是什么

- **articles/**：研究长文。完整论证链 + 全部脚注 + 官方原文链接。
- **notes/**：一手源留证（抓取日期、原文摘录、用途说明）。
- **topics.json**：选题台账，唯一真相源（状态、优先级、发布链接）。
- **assets/**：配图与封面。
- **scripts/**：索引生成、链接自检、提交推送。

## 方法论

**三色事实分层**（正文可分辨）：
- 【法】法律文本原文：全称 + 文号 + 公布日期 + 施行日期 + 条款号 + 官方链接。
- 【事】可核实事实：来源 + 时间点 + 截止日。
- 【判】作者判断：显式标注，不与前两者混同。

**一手源优先**：官方文本可作正文依据；二手解读只用于发现线索。征求意见稿、公布文本、生效文本三者分开写。

**留证强制**：每个被引用材料在 notes/ 留文件（URL、访问日期、逐字摘录、支撑哪句结论）。

**每篇三件套**：资料截止日 + 一句话结论 + 可执行落点（合规动作或尽调问题清单）。
