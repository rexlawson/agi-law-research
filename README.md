# AGI 法律研究

我是企业法务出身。写这个仓库有两个原因：一是 AI 的监管规则这两年变得太快，只做规则搬运没意思；二是自己打算投 AI 公司，想把"规则怎么落地"和"投的时候怎么查"放在一起看。

所以这里的文章有个固定落点：**这项规则由谁承担、成本落在谁头上、尽调的时候怎么查。**
